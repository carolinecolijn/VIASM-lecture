# VIASM lecture: Epidemiological Applications of Phylogenetics

This repo exists to share lecture slides and a few of the resources they link to. 

The slides are [here](epidemiological-applications-phylogenetics.pdf).

- McLaughlin et al., SARS-CoV-2 in Canada: https://elifesciences.org/articles/73896
- Lemey et al. 2009 Bayesian phylogeography, PLoS Comp Biol: https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1000520
